# 股票摊平计算器 (Stock Averaging Calculator Ultimate)

> **智能量化补仓与回本推演终端** · 单文件纯前端无依赖，极速开箱即用。

---

## 🌟 核心特性

- 📊 **持仓盈亏全景看板**：实时加权平均持仓成本、总成本、浮动盈亏（金额与百分比），支持自定义手续费与整手取整。
- 🎯 **单笔补仓推演 (What-If)**：
  - 目标成本模式：设定想摊到的成本价，自动反推所需最少补仓股数及所需追加资金。
  - 计划股数模式：设定补仓股数，实时计算补仓后的新成本价与新回本线。
- 🪜 **极限阶梯补仓推演 (DCA Ladder)**：
  - 模拟极端单边下跌行情，逐轮计算防破破损上限所需的补仓梯度与资金消耗。
  - 支持备用预算上限约束，避免越补越陷。
- 📏 **价格定位标尺**：动态可视化呈现当前现价、持仓成本价、回本线及历史成交买卖点。
- 🌓 **深色/浅色双主题一键无缝切换**。
- 📋 **持仓简报一键复制**：快速导出诊断文本分享至交流群或笔记。
- 💾 **本地离线持久化**：使用 `localStorage` 自动记忆历史买卖记录与推演参数，数据不出本地浏览器，绝对私密安全。
